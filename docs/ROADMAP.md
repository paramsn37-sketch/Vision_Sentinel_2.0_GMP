# Roadmap (out of scope for v2.0)

Items deliberately left out of v2.0 (blueprint §2.4), roughly in priority order.

1. Full GPU training run with Kaggle SH17 and Roboflow PPE sets (the notebook in `training/notebooks/` is ready).
2. Face-mask class (no reachable training data in the v2.0 build environment).
3. Cross-camera re-identification and multi-camera site maps.
4. Alert delivery (email, SMS, Teams) through the webhook hook point.
5. Role-based access control with several user accounts.
6. Edge deployment (Jetson / ONNX Runtime with TensorRT).
7. IoT sensor fusion (gas, noise, temperature).
8. Mobile companion app.
